# 🎯 AI Resume & Interview System

A full-stack AI-powered web application built with Spring Boot and React.

## Features
- 📄 AI Resume Scoring (score out of 100)
- 🎤 Mock Interview Practice
- 📊 Detailed AI Feedback
- 🔒 Secure Authentication
- 📥 Export Results

## Tech Stack
- **Backend:** Spring Boot 3.5, Spring Security, MySQL, JPA
- **Frontend:** React 18, Axios, React Router
- **Database:** MySQL (XAMPP)
- **AI:** Mock AI Scoring Engine

## Setup Instructions

### Backend
1. Install XAMPP and start MySQL
2. Create database `airesume_db`
3. Update `application.properties` with your DB credentials
4. Run `mvn spring-boot:run`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm start`
